# P7 — 到期处理中心与系统通知

## 目标

在不连接券商的前提下，把「哪些合约快到期 / 已过期、各自要做什么」集中到一个可操作页面，并让用户在应用最小化或隐藏到托盘时仍能收到一次汇总提醒。

## 到期阶段

| 阶段 | 条件 | 含义 |
|---|---|---|
| `overdue` | `daysLeft < 0` | 已过到期日，必须先与券商核对实际处理 |
| `today` | `daysLeft == 0` | 美东交易日今天到期 |
| `critical` | `1..=min(3, leadDays)` | 3 天内到期（提醒期小于 3 天时取提醒期） |
| `soon` | 其余 `<= leadDays` | 提醒期内但尚未进入紧急区间 |

`daysLeft` 与侧栏徽标、仪表盘、到期日历共用后端 `views::position` 的美东交易日口径。`leadDays` 来自 `reminderLeadDays`（0–60，默认 7）。

## 扫描与通知

`notifications::scan` 遍历全部未归档账户，逐个重放事件并收集提醒期内的未平仓合约，按剩余天数、账户名、合约排序。

`notifications::check_and_notify`：

1. 读取偏好；系统通知关闭时仍返回各类数量，但不发送、不写日志。
2. 按 `账户 ID|合约|到期日|阶段` 生成去重键，过滤已发送过的条目。
3. 仅当存在新条目时发送**一条**聚合通知，正文列出最多 3 个合约并附「另有 N 个」及已过期 / 今天 / 3 天内数量。
4. 发送成功后才把本次条目与当日日期写入 `expiryNotificationLog`；发送失败不标记，下次仍会重试。
5. 日志为 settings 键值 JSON，保留 90 天、最多 500 条；损坏时按空日志处理，不阻塞应用。

同一合约同一阶段只提醒一次；进入下一阶段（例如 7 天内 → 3 天内 → 今天 → 已过期）会再次提醒。合约部分平仓或数量变化不单独触发提醒，避免同一阶段重复打扰。

## 托盘与后台

- 托盘图标 ID `main`，提示文字随检查结果更新为「无到期提醒」或「N 个到期提醒（M 个已过期）」。
- 左键恢复并聚焦主窗口；右键菜单提供「打开」「检查到期」「退出」。
- 后台线程启动 5 秒后检查一次，此后每小时一次；使用 `AppState::try_conn`，数据库被占用时跳过本轮。
- `systemNotificationsEnabled` 与 `closeToTray` 均默认关闭。开启关闭到托盘后，窗口 `CloseRequested` 被拦截并隐藏窗口；真正退出使用托盘菜单。
- 托盘菜单的「检查到期」与 UI 的「检查到期并通知」调用同一命令，结果一致。

## 交互

- 侧栏新增「到期处理」入口，徽标与提示从「当前持仓」移到这里。
- 汇总条：已过期、今天到期、3 天内、提醒期内、提醒期内 Put 资金义务。
- 分组表：合约、手数、到期日、剩余天数、净权利金、Put 资金义务、操作。
- 行内操作预填「买入平仓 / 到期作废 / 指派」的标的、到期日、行权价、方向、乘数、手数；作废日期默认到期日，其余默认今天。另可跳转战役详情。
- 已过期分组显示前置警告：先核对券商，再按作废 / 指派 / 平仓录入。
- 「检查到期并通知」显示各类数量与新通知数；没有新通知时明确说明。

## 存储与兼容

- 未新增表或列，schema 仍为 4。
- 两个偏好与通知日志均写入既有 `settings` 键值表：`systemNotificationsEnabled`、`closeToTray`、`expiryNotificationLog`。
- 通知日志是派生状态，可安全删除；恢复旧备份后最多重新提醒一次当前阶段。

## 主要改动

- `wheel-app`：`notifications` 模块（扫描、分阶段去重、发送、托盘提示）、托盘与窗口关闭拦截、每小时后台检查、`check_expiries` / `send_test_notification` IPC、偏好字段与校验。
- UI：`ExpiryCenter.tsx`、导航与徽标移动、设置页通知 / 托盘开关与测试通知。
- 依赖：`tauri` 启用 `tray-icon`，新增 `tauri-plugin-notification`；capability 增加 `notification:default`。

## 验证

- `cargo test --offline --workspace`：阶段分组、排除归档账户、同阶段去重、关闭通知仍统计、日志清理、发送失败不标记。
- `cargo clippy --offline -p wheel-app --no-deps -- -D warnings`
- `npm --prefix ui run build`
- Playwright：分组与金额、检查通知结果、行内作废预填、通知 / 托盘设置保存与测试通知。

## 已知限制

- 通知只在应用运行时检查；完全退出后不会提醒，Windows 通知权限被关闭时只能看应用内列表。
- 每个阶段每合约只发一次，没有贪睡、按合约定制或指定时间提醒。
- 托盘图标与通知目前只针对 Windows x64 发布目标验证。
- 不连接券商：过期合约不会自动作废或释放资金义务，仍需人工核对后录入。
