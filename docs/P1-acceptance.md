# P1 开发与验收记录

日期：2026-11-03。

## 本批实现

React / TypeScript / Vite 前端与 Tauri / SQLite 后端接通，覆盖仪表盘、持仓、录入、战役详情、台账、手动价格和数据检查。

- 入账在事务中重放完整历史并检查不变量，失败不写库。
- 滚动两条事件原子入账；第二条重放失败或 SQL 失败均不留下第一条。
- 撤销为软删除，保留原始事件和序号；后续交易依赖被撤销记录时拒绝操作。
- 旧数据库幂等迁移 `deleted_at`，历史事件不丢失。
- 拒绝无效方向、非有限金额、负费用、零股数等非法字段。
- SQLite 快照保留账户、价格和全部事件（含撤销记录），不覆盖既有备份。
- 保存完成后阻止同一笔重复提交；继续录入模式清空成交值。
- CSV 保护文本公式并保留负数金额的数值类型。
- 成本口径开关持久化到 SQLite，默认关闭；开启后分红摊薄 B/C′，A 保持不变，历史成本图同步重算。快照包含此设置。
- 核心重放记录每笔事件的战役归属，时间轴按交易日期、同日序号排列；同日清仓后重新建仓不会串入上一轮事件。
- 对每个现有 Call 独立模拟全部未平仓手数被指派，按真实合约乘数计算，预估指派费用为零；预览不写库。
- 只有持股和期权全部清空才显示本轮总收益；部分指派展示累计已实现收益和剩余持仓，排除未平仓权利金与剩余股票浮盈亏。
- 成本设置保存后等待刷新；应用信息读取失败不会阻断新财务数据，财务读取失败则隐藏旧金额并提供重试入口。

## 标的查询与自动行情增强

- 原“价格与数据”拆分为“行情”和“设置”。设置内分为成本口径、备份与维护、交易记录。
- 交易录入支持美股 / ETF 的代码或公司名称下拉查询，键盘选择、常用标的离线回退；自动展示标的参考价，不覆盖成交价或期权权利金。
- 腾讯财经公开行情：进行中战役启动时及应用可见时每 5 分钟刷新，支持单个标的刷新与查询后更新到账本。刷新中新增标的进入队列，最多每批 50 个。
- SQLite 幂等迁移价格来源和美东报价时间，保留原手动报价。失败保留旧价格，部分成功逐项报告；同日旧自动时间戳不覆盖新自动报价。手动校准保留在行情页。
- 行情可能延迟，界面显示来源、原报价时间及独立的本地检查时间；不保证实时性。历史交易与成本重放不依赖网络。
- 最新验证：42 项离线 Rust 测试通过；另行执行的真实联网测试通过，覆盖 Apple 搜索及 AAPL / MSFT / BRK.A / BRK.B / SPY 报价。桌面 crate 含测试的严格 Clippy 通过。
- 19 项 Playwright 测试通过，新增启动与定时刷新、请求期间新增持仓排队、搜索键盘选择、旧搜索响应丢弃、断网录入、报价元数据、部分失败、手动校准、设置分栏与窄屏布局。仍使用合成 IPC，不代表原生完整端到端验收。
- 前端生产构建和 Tauri 调试版构建通过，产物仍为 `target/debug/wheel-app.exe`。

## 人工验收

请使用单独测试数据库：卖 Put → 作废 → 再卖 Put → 指派 → 卖 Call → 作废或平仓 → 滚动 → 清空股票并结算。逐步核对 A/B/C′、台账与股票批次。更新手动价格，验证现价与成本线；验证可撤销的末笔事件及被依赖事件的拒绝；导出 CSV，创建并离线打开备份副本。
