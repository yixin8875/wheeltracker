# Wheel Tracker

本地优先的美股期权车轮策略成本账本。Rust 重放交易事件，Tauri 2 提供桌面窗口，React + TypeScript 提供录入与复盘界面。统一以 USD 记账，不连接券商下单。

## 已实现

- 仪表盘：当前战役、已落袋与未平仓净权利金、Put 资金义务。
- 股票与期权持仓：到期倒计时、过期提示、预填平仓 / 作废 / 指派。
- 快速录入：期权生命周期、股票买卖、分红、费用、现金调整；Ctrl+N 打开。
- 滚动录入：BTC + STO 一次提交，任何一条失败则整体回滚。
- CSV 导入：选择文件或粘贴文本，自动识别中英文表头；三步确认列映射与逐行结果，重复行默认排除，任一行非法则整批不入账。
- 邮件导入：选择 `.eml` / `.txt` 或粘贴正文，本地解码 multipart、base64、quoted-printable 与 HTML；按 Schwab、Fidelity、IBKR、富途、老虎和通用成交确认抽取，无法确定的行会说明并跳过，确认后复用 CSV 的校验与事务入账。
- 截图 OCR：调用 Windows 内置 `Windows.Media.Ocr`（离线），可选择图片或在页面内 Ctrl+V 粘贴；识别文字先展示为可编辑文本，修正后再解析。OCR 数字可能出错，必须逐行核对。
- 战役详情：A / B / C′ 三轨成本阶梯图、数据表、股票批次、本轮收租及按日期排序的事件时间轴。
- 成本设置：可将累计分红计入 B / C′ 成本，设置保存在 SQLite，历史成本图随口径重算。
- Call 指派预览：逐个合约独立模拟全部未平仓手数被指派，拆分股票盈亏、期权收益、分红和现金调整；部分指派明确展示剩余持仓。
- 到期提醒：按可配置的提前天数（默认 7 天）在侧栏显示数量徽标，仪表盘列出即将到期与已过期合约；仅应用内提醒，不发送系统通知。
- 到期日历：周一起始的 UTC 月历，按日显示未平仓合约，附未来 30 天到期条与当日合约明细。
- 战役对比：按战役聚合并绘制「持续天数 × 已实现收益率」散点图，按标的着色，进行中空心、已结束实心，并提供精确数据表。
- 收租月报：按 UTC 月份累计已落袋净收租、分红、独立费用与现金调整；柱形为月度合计、折线为区间累计，支持按年份筛选与 CSV 导出。
- 台账：标的、方向、状态、开仓日期筛选，CSV 与真实 `.xlsx` 导出（当前筛选结果）。
- Excel 工作簿：一次导出台账、交易记录、持仓、战役四张工作表；金额与百分比带数字格式，不生成公式。
- 盯市成本图：三轨成本叠加行情页已保存参考价、现价与当前 Call 行权价，逐台阶显示 Δ，附精确数据表。
- 标的下拉搜索：按代码 / 公司名称查找美股和 ETF，支持键盘选择及离线常用列表；选定后自动展示标的参考价。
- 行情：启动后获取进行中战役的报价，应用可见时每 5 分钟更新；支持逐标的刷新、来源 / 美东报价时间、离线缓存及手动校准。
- 多账户：侧栏快速切换，设置 → 账户新建（最多 50 个，名称唯一）或重命名；账户间事件、持仓、成本、台账与导入完全隔离，行情与成本口径保持全局。
- 设置：成本口径、账户、到期提醒、备份与维护、交易记录分栏；撤销并重算、全量重算检查。
- SQLite 备份：手动备份、每日自动备份（默认保留 7 份）与恢复前安全快照；包括事件、撤销审计、价格、成本与提醒设置，不覆盖既有备份。
- 备份恢复向导：校验完整性、事件数与必需表后暂存恢复；下次启动、打开 SQLite 前先归档当前库及 WAL/SHM 再替换，失败自动回滚，暂存期间拒绝写入。
- 备份加密：手动备份可设置 8–128 位密码，生成 `.sqlite.enc`（PBKDF2-HMAC-SHA256 + AES-256-GCM）；校验与恢复加密备份需输入密码，恢复用明文副本在替换后立即删除。
- JSON 导出：一次导出所有账户的事件、报价与设置，便于查看、审阅或迁移；JSON 不是可恢复快照。

A = 纯股票成本；B = 扣除已落袋净权利金；C′ = 再扣除未平仓净权利金。分红默认不摊薄成本，可在“设置 → 成本口径”开启，开启后 B/C′ 额外扣除累计分红。分红始终计入战役总收益。现金调整影响战役收支，不覆盖股票数量或成本。

Call 预览只模拟现有合约的指派，未来指派费按 $0 估算，不写入事件。只有股票与期权均清空的情景才显示“预计本轮总收益”；仍有持仓时显示累计已实现收益，排除剩余股票浮盈亏与未平仓权利金。多个情景独立计算，不可相加。

## 标的与行情

“记一笔”可按代码或公司名称搜索美股 / ETF，使用方向键与 Enter 选择。网络不可用时仍可选择常用标的或输入完整代码。选定后自动读取标的参考价，不会修改历史成交价、每股分红或期权权利金。

“行情”提供标的查询、涨跌幅、账本报价、来源与美东报价时间。进行中的战役启动时自动刷新，应用可见时每 5 分钟更新，也可手动更新持仓或单个标的。查询结果的“更新到账本”保存参考价；“记录交易”只预填代码。

行情来自腾讯财经公开接口，无需 API Key，可能延迟或因网络 / 服务变更不可用，不保证实时性。应用向行情源发送搜索文字与标的代码，不发送交易历史。失败会明确提示，已有价格保留；历史行情不会被标为当前实时价。报价时间为行情源的美东时间，本地检查时间单独标注。

账本使用每个标的日期最新的已保存报价。手动价格移至“行情 → 手动校准价格”，同日的后续自动更新会替换校准价；较旧的自动时间戳不能覆盖较新的自动报价。旧数据库自动迁移并将原报价标为手动。报价仅用于现价与成本线对照，不改变事件、持仓或 A/B/C′ 成本。

## 环境与启动

Windows 11，Rust MSVC 工具链、Visual Studio C++ Build Tools、WebView2 Runtime，Node.js 22 或更新版本。首次构建需要下载依赖。

在仓库根目录安装前端依赖：

```bash
npm --prefix ui install
```

启动桌面程序（自动启动 Vite）：

```bash
npm --prefix ui run desktop
```

构建调试版可执行文件：

```bash
npm --prefix ui run desktop:build -- --debug --no-bundle
```

输出：`target/debug/wheel-app.exe`。Windows NSIS 正式安装包：

```bash
npm --prefix ui run desktop:build -- --bundles nsis
```

输出：`target/release/bundle/nsis/Wheel Tracker_0.2.0_x64-setup.exe`。本轮已成功构建；安装与原生完整流程的验收状态见[桌面验收记录](docs/desktop-acceptance.md)。

单独预览前端：

```bash
npm --prefix ui run dev
```

浏览器模式仅用于界面预览，显示明确提示，不提供模拟账本。

## 数据与备份

桌面程序使用平台应用数据目录下的 `wheel.db`，实际路径可在“设置”中查看。备份写入数据库旁的 `backups/`，成功后显示完整路径；文件时间按 UTC 显示。重要备份应另存到其他设备。

自动备份在应用启动时和每 30 分钟检查一次 UTC 日期，每天最多生成一份 `auto-*.sqlite`。保留份数可在“设置 → 备份与维护”调整（1–100，默认 7）；自动清理只删除自动备份，手动备份与 `pre-restore-*.sqlite` 安全快照永不自动删除。

恢复在“设置 → 备份与维护”中选择备份并校验：只有完整性检查通过、必需表和列齐全的 SQLite 才能恢复。暂存后必须完全退出并重新启动；应用在打开 SQLite 之前先把当前库及 WAL/SHM 归档，再替换为所选备份。替换失败会保留原库并记录失败原因。暂存恢复期间所有写入会被拒绝。

手动备份时可填写加密密码：留空生成普通 `.sqlite`，填写 8–128 位密码则生成 `.sqlite.enc`。加密备份在列表中带锁标记，校验与恢复都必须输入同一密码；暂存时会解密出临时副本，替换完成或失败后都会删除明文副本，原加密备份保留。密码不会保存，遗失后无法恢复。每日自动备份与恢复前安全快照始终为普通 SQLite。

CSV / Excel 导出是报表；CSV 导入用于补录历史交易，重复行默认排除，确认后可强制导入。邮件与截图导入都在本地完成：邮件正文不联网，截图通过系统临时目录调用本机 OCR，结束后删除临时图片与脚本；识别结果不会上传。JSON 导出包含所有账户的完整事件日志、报价与设置，适合审阅和迁移，但不能直接恢复；完整备份应使用 SQLite 快照。
