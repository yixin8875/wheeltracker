# Wheel Tracker

本地优先的美股期权车轮策略成本账本。Rust 重放交易事件，Tauri 2 提供桌面窗口，React + TypeScript 提供录入与复盘界面。统一以 USD 记账，不连接券商下单。

## 已实现

- 仪表盘：当前战役、已落袋与未平仓净权利金、Put 资金义务；账户现金面板显示现金覆盖率与缺口。
- 股票与期权持仓：到期倒计时、过期提示、预填平仓 / 作废 / 指派。
- 快速录入：期权生命周期、股票买卖、拆股 / 合股、分红、费用、现金调整、账户级入金 / 出金；Ctrl+N 打开。
- 期权乘数：期权合约按实际每手股数录入（默认 100）；权利金、占用资金、指派预览、年化与到期提醒均使用真实乘数。
- 拆股 / 合股：按「分子 : 分母」记录，自动调整进行中战役的持股数、未平仓期权的行权价与每手股数；零股按「整数股 + 现金补偿」入账，不保留小数股。拆股后的原合约仍可平仓、指派或作废。
- 滚动录入：BTC + STO 一次提交，任何一条失败则整体回滚。
- CSV 导入：选择文件或粘贴文本，自动识别中英文表头；三步确认列映射与逐行结果，确认页可逐行修改日期、类型、标的、数量、价格、费用、合约与乘数；支持账户级入金 / 出金行（带金额、不带标的与合约）；重复行默认排除，任一行非法则整批不入账。每次导入生成批次 ID，可在「最近导入」整批撤销；同日平仓 / 开仓混排会提示先平后开。
- AI 截图导入：在「设置 → AI 识别」配置 OpenAI 兼容的 Base URL、模型与 API Key（支持 OpenAI、通义、智谱、OpenRouter 等），再到导入页选择 PNG / JPEG / WebP / GIF 或 Ctrl+V 粘贴。截图会发送到你配置的视觉服务，模型返回结构化交易，经后端逐字段校验后进入逐行确认；不会自动入账。选择图片后先显示缩略图与目标服务，点「确认上传并识别」才会上传；识别结果同样可整批撤销。
- 战役详情：A / B / C′ 三轨成本阶梯图、数据表、股票批次、本轮收租及按日期排序的事件时间轴。
- 成本设置：可将累计分红计入 B / C′ 成本，设置保存在 SQLite，历史成本图随口径重算。
- Call 指派预览：逐个合约独立模拟全部未平仓手数被指派，拆分股票盈亏、期权收益、分红和现金调整；部分指派明确展示剩余持仓。
- 到期提醒：按可配置的提前天数（默认 7 天）在侧栏显示数量徽标，仪表盘列出即将到期与已过期合约；仅应用内提醒，不发送系统通知。
- 到期日历：周一起始的美东交易日历，按日显示未平仓合约，附未来 30 天到期条与当日合约明细。
- 战役对比：按战役聚合并绘制「持续天数 × 已实现收益率」散点图，按标的着色，进行中空心、已结束实心，并提供精确数据表。
- 收租月报：按美东交易日月份累计已落袋净收租、分红、独立费用与现金调整；柱形为月度合计、折线为区间累计，支持按年份筛选与 CSV 导出。
- 年度报表：按美东交易日年份汇总已实现口径的净收租、股票已实现盈亏（卖出 / Call 指派 / 拆股零股补偿）、分红、费用与现金调整；柱形为月度合计、折线为年度累计，附按标的归因表，支持 CSV 与两张工作表的 Excel 导出。
- 台账：标的、方向、状态、开仓日期筛选，CSV 与真实 `.xlsx` 导出（当前筛选结果）。
- 交易记录：台账页签内按标的 / 类型 / 日期筛选，显示金额与拆股零股补偿，可单笔修改 / 撤销并导出当前筛选 CSV；修改保留原记录 ID 与序号并重新回放整本账，后续交易依赖时拒绝；战役时间轴也可直接撤销。
- Excel 工作簿：一次导出台账、交易记录、持仓、战役四张工作表；金额与百分比带数字格式，不生成公式。
- 盯市成本图：三轨成本叠加行情页已保存参考价、现价与当前 Call 行权价，逐台阶显示 Δ，附精确数据表。
- 标的下拉搜索：按代码 / 公司名称查找美股和 ETF，支持键盘选择及离线常用列表；选定后自动展示标的参考价。
- 行情：启动后获取进行中战役的报价，应用可见时每 5 分钟更新；支持逐标的刷新、来源 / 美东报价时间、离线缓存及手动校准。
- 账户现金与对账：记录入金 / 出金后，账户现金 = 全部交易现金流 + 累计入金 − 累计出金；有未平仓 Put 时显示现金覆盖率与缺口。未记录任何入金 / 出金时只显示交易现金流净额，并提示不含期初余额。「与券商对账」只读对照券商现金与最近 60 笔现金变动，不修改账本。入金 / 出金不计入战役收益，也不影响 A / B / C′ 成本。设计记录见[账户现金与 Put 覆盖](docs/P6-cash.md)。
- 多账户：侧栏快速切换，设置 → 账户新建（最多 50 个，名称唯一）、重命名、归档 / 恢复或删除空账户；账户间事件、持仓、成本、台账与导入完全隔离，行情与成本口径保持全局。
- 导航：按「日常 / 账本 / 复盘」分组；收租月报、年度报表、战役对比合并到「报告」页签，侧栏保留 8 个入口，设置固定在底部账户区。
- 设置：成本口径、账户、到期提醒、AI 识别、备份与维护；重算并检查账本。
- SQLite 备份：手动备份、每日自动备份（默认保留 7 份）与恢复前安全快照；包括事件、撤销审计、价格、成本与提醒设置，不覆盖既有备份。
- 备份恢复向导：校验完整性、事件数与必需表后暂存恢复；下次启动、打开 SQLite 前先归档当前库及 WAL/SHM 再替换，失败自动回滚，暂存期间拒绝写入。
- 备份加密：手动备份可设置 8–128 位密码，生成 `.sqlite.enc`（PBKDF2-HMAC-SHA256 + AES-256-GCM）；校验与恢复加密备份需输入密码，恢复用明文副本在替换后立即删除。
- JSON 导出：一次导出所有账户的事件、报价与设置，便于查看、审阅或迁移；JSON 不是可恢复快照。

A = 纯股票成本；B = 扣除已落袋净权利金；C′ = 再扣除未平仓净权利金。入金 / 出金是账户资金划转，不参与成本或收益。分红默认不摊薄成本，可在“设置 → 成本口径”开启，开启后 B/C′ 额外扣除累计分红。分红始终计入战役总收益。现金调整影响战役收支，不覆盖股票数量或成本。

Call 预览只模拟现有合约的指派，未来指派费按 $0 估算，不写入事件。只有股票与期权均清空的情景才显示“预计本轮总收益”；仍有持仓时显示累计已实现收益，排除剩余股票浮盈亏与未平仓权利金。多个情景独立计算，不可相加。

## 标的与行情

“记一笔”可按代码或公司名称搜索美股 / ETF，使用方向键与 Enter 选择。网络不可用时仍可选择常用标的或输入完整代码。选定后自动读取标的参考价，不会修改历史成交价、每股分红或期权权利金。

“行情”提供标的查询、涨跌幅、账本报价、来源与美东报价时间。进行中的战役启动时自动刷新，应用可见时每 5 分钟更新，也可手动更新持仓或单个标的。查询结果的“更新到账本”保存参考价；“记录交易”只预填代码。

行情来自腾讯财经公开接口，无需 API Key，可能延迟或因网络 / 服务变更不可用，不保证实时性。应用向行情源发送搜索文字与标的代码，不发送交易历史。失败会明确提示，已有价格保留；历史行情不会被标为当前实时价。报价时间为行情源的美东时间，本地检查时间单独标注。

账本使用每个标的日期最新的已保存报价。手动价格移至“行情 → 手动校准价格”，同日的后续自动更新会替换校准价；较旧的自动时间戳不能覆盖较新的自动报价。旧数据库自动迁移并将原报价标为手动。报价仅用于现价与成本线对照，不改变事件、持仓或 A/B/C′ 成本。

## 环境与启动

Windows 11，Rust MSVC 工具链、Visual Studio C++ Build Tools、WebView2 Runtime，Node.js 22 或更新版本。首次构建需要下载依赖。

在仓库根目录安装前端依赖：

```bash
npm --prefix ui install
```

启动桌面程序（自动启动 Vite）：

```bash
npm --prefix ui run desktop
```

构建调试版可执行文件：

```bash
npm --prefix ui run desktop:build -- --debug --no-bundle
```

输出：`target/debug/wheel-app.exe`。Windows NSIS 正式安装包：

```bash
npm --prefix ui run desktop:build -- --bundles nsis
```

输出：`target/release/bundle/nsis/Wheel Tracker_0.5.6_x64-setup.exe`。

每次推送到 `main`，`.github/workflows/release.yml` 会自动把补丁版本 +1、提交版本号、打 `vX.Y.Z` 标签、重新构建 NSIS 安装包并发布 GitHub Release。自动提交带 `[skip release]`，不会递归触发；本地提交本身不会触发，需要推送到 `main`。

单独预览前端：

```bash
npm --prefix ui run dev
```

浏览器模式仅用于界面预览，显示明确提示，不提供模拟账本。

## 发布

一条命令完成版本一致性检查、测试、前端构建、NSIS 打包与哈希清单：

```bash
python -I scripts/release.py
```

先跑检查但不重新打包：

```bash
python -I scripts/release.py --no-build
```

产物在 `dist/release/`：`<installer>.sha256`（`<hex>  <filename>`）、`release-manifest.json`（版本、提交、UTC 构建时间、目标、文件大小、SHA-256）与 `latest.json`（更新签名与下载地址）。安装包本身未做代码签名；安装、覆盖升级、卸载与 CSP 冒烟按[发布检查清单](docs/release-checklist.md)执行。MIT 许可证见 `LICENSE`。

## 自动更新

桌面应用启动时检查 `https://github.com/yixin8875/wheeltracker/releases/latest/download/latest.json`。发现新版本时会在页面顶部显示更新横幅，点击「下载并安装」后自动下载、验签并运行安装器，完成后点击「重启应用」生效。更新包使用 Tauri minisign 签名；公钥写在 `crates/wheel-app/tauri.conf.json`，私钥只保存在 GitHub Actions secret `TAURI_SIGNING_PRIVATE_KEY` 中，不进入版本库。

## 数据与备份

桌面程序使用平台应用数据目录下的 `wheel.db`，实际路径可在“设置”中查看。备份写入数据库旁的 `backups/`，成功后显示完整路径；文件时间按 UTC 时间戳显示（与美东交易日不同）。重要备份应另存到其他设备。

自动备份在应用启动时和每 30 分钟检查一次 UTC 日期，每天最多生成一份 `auto-*.sqlite`。保留份数可在“设置 → 备份与维护”调整（1–100，默认 7）；自动清理只删除自动备份，手动备份与 `pre-restore-*.sqlite` 安全快照永不自动删除。

恢复在“设置 → 备份与维护”中选择备份并校验：只有完整性检查通过、必需表和列齐全的 SQLite 才能恢复。暂存后必须完全退出并重新启动；应用在打开 SQLite 之前先把当前库及 WAL/SHM 归档，再替换为所选备份。替换失败会保留原库并记录失败原因。暂存恢复期间所有写入会被拒绝。

手动备份时可填写加密密码：留空生成普通 `.sqlite`，填写 8–128 位密码则生成 `.sqlite.enc`。加密备份在列表中带锁标记，校验与恢复都必须输入同一密码；暂存时会解密出临时副本，替换完成或失败后都会删除明文副本，原加密备份保留。密码不会保存，遗失后无法恢复。每日自动备份与恢复前安全快照始终为普通 SQLite。

CSV / Excel 导出是报表；CSV 导入用于补录历史交易，确认页可逐行修改字段，重复行默认排除，确认后可强制导入；每次导入可在「最近导入」整批撤销。AI 截图导入会把图片发送到你在设置中配置的 OpenAI 兼容服务，因此必须显式同意后才能启用；模型输出只作为草稿，经过字段校验并逐行确认后才会写入账本。API Key 以明文保存在本机 SQLite，会随 SQLite 备份（包括自动备份）复制，但不会出现在 JSON 导出中；建议使用单独的低额度 Key，重要备份请设置密码。JSON 导出包含所有账户的完整事件日志、报价与设置，适合审阅和迁移，但不能直接恢复；完整备份应使用 SQLite 快照。
